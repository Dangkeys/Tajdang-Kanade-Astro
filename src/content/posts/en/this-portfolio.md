## The starting point

This website is a fork of [Kanade](https://github.com/sudoriaa/Kanade-Astro), an open source blog built with Astro, Vue, and Tailwind CSS. Credit for the original theme belongs to Kanade’s creator.

## Making it mine

I’m adapting the theme into a portfolio with a single home page, searchable posts, English and Thai, and a coral and plum palette inspired by the L banner.

Projects, work experience, activities, and skills share the same post format. That keeps the site simple while leaving room to explain each piece of work in detail.

## Current scope

This is a static website. Search and category filters run in the browser; there is no application backend. This write-up documents the site itself, rather than claiming a production infrastructure deployment.
