## เว็บไซต์นี้

ผม fork [Kanade](https://github.com/sudoriaa/Kanade-Astro) มาปรับเป็นเว็บส่วนตัว

ใช้ Astro, Vue และ Tailwind CSS เปลี่ยนสีให้เข้ากับแบนเนอร์ L เพิ่มหน้าไทย / อังกฤษ ค้นหาโพสต์ แท็กซ้อน และแกลเลอรีรูป

เว็บเป็น static ส่วนค้นหากับตัวกรองทำงานในเบราว์เซอร์ครับ

[Repository ของเว็บ](https://github.com/Dangkeys/Tajdang-Kanade-Astro)
