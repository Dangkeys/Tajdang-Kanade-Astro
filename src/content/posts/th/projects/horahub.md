## งาน Backend

ผมเริ่มทำ HoraHub ในเดือน ก.ย. 2025 เป็น marketplace สำหรับบริการดูดวง

ผมทำ API ด้วย NestJS ออกแบบ schema ใน PostgreSQL ทำระบบตรวจสอบผู้ให้บริการ leaderboard และแชตแบบ real-time ด้วย Socket.io
